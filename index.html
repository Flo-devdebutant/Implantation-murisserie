Mon compte

Synchronisation entre appareils

Partagez les mêmes journées entre le bureau, la tablette du quai et les téléphones. Un code relie les appareils entre eux ; sans code, rien n'est envoyé. L'historique est publié mois par mois : chaque enregistrement ne renvoie que le mois en cours.

Jours non travaillés

Le dimanche est toujours chômé. Les jours fériés le sont par défaut : décochez ceux que vous travaillez. Un jour chômé est reconduit automatiquement depuis le dernier jour renseigné, en suivant les projections prévues.

Sauvegarde automatique

Chaque modification est enregistrée immédiatement dans ce navigateur. Rien ne part sur Internet tant que la synchronisation n'est pas activée.
